<h1>JoinBareng Quick Launch</h1>

<p>
  <strong>JoinBareng Quick Launch</strong> adalah ekstensi browser yang
  mempermudah kamu membuka JoinBareng dalam satu klik — dari toolbar, menu klik kanan,
  maupun pintasan keyboard. Cocok untuk pengguna yang sering mengecek marketplace,
  login dashboard, atau mengakses halaman bantuan JoinBareng.
</p>

<h2>Fitur Utama</h2>
<ul>
  <li><strong>1-klik buka JoinBareng</strong> via ikon toolbar / context menu / shortcut.</li>
  <li><strong>Pilih tujuan default</strong>: Beranda, Marketplace, Dashboard, atau Bantuan.</li>
  <li><strong>Pilih cara buka</strong>: tab baru atau ganti tab aktif.</li>
  <li><strong>UTM otomatis</strong> (opsional) untuk tracking asal kunjungan.</li>
  <li><strong>Menu klik kanan</strong> (context menu) untuk akses cepat dari halaman mana pun.</li>
  <li><strong>Pintasan keyboard</strong> bawaan (<code>Alt + Shift + J</code>) — bisa diubah.</li>
  <li><strong>Desain ringan</strong>, tidak ada host permissions, tidak menyentuh konten halaman.</li>
</ul>

<h2>Kenapa Perlu Menggunakan?</h2>
<ul>
  <li><strong>Cepat & efisien</strong> — hemat waktu, tanpa ketik URL.</li>
  <li><strong>Fleksibel</strong> — semua perilaku bisa disesuaikan di halaman pengaturan.</li>
  <li><strong>Aman & privat</strong> — tidak membaca data, tidak melakukan tracking.</li>
  <li><strong>Ringan</strong> — tidak membebani browser, bekerja lokal sepenuhnya.</li>
</ul>

<h2>Cara Menggunakan</h2>
<ol>
  <li>Klik ikon ekstensi → pilih halaman JoinBareng yang ingin dibuka.</li>
  <li>Atur preferensi di menu popup atau di halaman Options.</li>
  <li>Gunakan shortcut <code>Alt + Shift + J</code> untuk buka lebih cepat.</li>
  <li>Klik kanan halaman apa pun → “Buka JoinBareng”.</li>
</ol>

<h2>Izin yang Digunakan</h2>
<ul>
  <li><strong>storage</strong> — menyimpan preferensi (lokal, tidak dikirim ke server).</li>
  <li><strong>tabs</strong> — untuk membuka/ganti tab JoinBareng.</li>
  <li><strong>menus</strong> — untuk membuat menu klik-kanan.</li>
</ul>

<h2>Privasi</h2>
<ul>
  <li>Ekstensi ini <strong>tidak mengumpulkan atau mengirim data pengguna</strong>.</li>
  <li>Tidak ada analytics, tracking, atau penggunaan eksternal.</li>
  <li>Semua logika berjalan lokal di browser.</li>
</ul>

  Tidak mewakili atau berafiliasi resmi dengan merek/layanan premium lain;
